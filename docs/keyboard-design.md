# 默认虚拟键盘

默认键盘采用中性深色面板、圆角键帽和薄荷色焦点，保留熟悉的 QWERTY 顺序。当前默认面板截图见 [UGUI](https://media.githubusercontent.com/media/magicskysword/SkyKeyYuyan/main/ui/Screenshots/ugui-composition.png) 和 [FairyGUI](https://media.githubusercontent.com/media/magicskysword/SkyKeyYuyan/main/ui/Screenshots/fairygui-composition.png)。

正文光标处显示带下划线的临时组字，候选词以紧凑横向浮窗跟随该行显示。浮窗优先出现在光标下方，空间不足时翻到上方，水平位置限制在玩家面板内。

## 布局

键盘宽度分为二十八个逻辑单位，即十四个等宽键位。普通字符键占两个单位，各排左侧对齐，Q/A/Z、W/S/X 等同列键中心垂直对应。功能键宽度为普通键的整数倍，各排之间保留间距。

| 排 | 内容 |
| --- | --- |
| 数字排 | 数字、减号、等号和加宽退格 |
| 第一字母排 | QWERTY、左右括号和加宽向前删除 |
| 第二字母排 | ASDF 字母、分号、引号和加宽换行 |
| 第三字母排 | ZXCV 字母、逗号、句号、斜杠、Shift 和清空 |
| 空格排 | 语言、补全、长空格以及左、上、下、右光标键 |
| 操作排 | 全选、重试转换、取消和完成 |

中文、英语及韩语使用相同的空间结构，字符标签、输出和 Shift 形式由语言布局提供。正文和草稿沿用宿主的混合语言字体。

正文可按次选择单行或多行。多行的最低显示行数默认为三，可设为一至五；内容增多时视口随排版增高，最多显示五行，更多内容由原生输入控件滚动查看。键盘及下方操作区随视口高度一起移动，整体面板仍按玩家区域缩放。

候选浮窗按当前字体测得的文字宽度紧凑排列。候选按钮至少宽四十八个逻辑像素，文字两侧各留十二个像素，相邻按钮间隔八个像素；词组随文字长度扩展。同一行展示能完整容纳的连续候选，浮窗宽度随可见候选收缩，手柄切换选择时，可见区跟随选中项。候选页或字体变化时重新测量宽度，其余状态更新复用测量结果。

临时显示将组字投影到正文当前选区，确认候选后写入正文，保持前后文本和代理对完整。长单行水平滚动、多行超过视口时垂直滚动，使临时光标与候选浮窗保持可见。指针重新定位前提交当前组字；提交仍在等待查询或写入处理时，正文等待其完成。

## 手柄反馈

玩家连接并启用手柄时，键盘焦点同时使用高对比填色、明显轮廓和 A 标记；断开后隐藏，重连后恢复。候选选中状态与按键焦点分别展示。上下导航保留同一逻辑列中心，上下折返返回对应按键；按 A 输入后继续保留该中心，横向移动或指针激活后重新定位。横向按空间顺序循环。

能力不可用的功能键保持位置并降低明度，方向导航跳过这些按键。底部提示按当前模式展示左摇杆、右摇杆和摇杆按下的含义，文字在相应区域居中。X 确认选词，Y 切换语言，Start 保存并关闭面板。

按下任一摇杆进入正文编辑，再次按下返回键盘。正文编辑时突出正文边框，左摇杆移动光标，右摇杆扩展选区；退出后保留正文选区与原来的键盘焦点。指针点击正文同样进入正文编辑，点击虚拟按键则返回键盘。

UGUI 和 FairyGUI 使用同一份布局数据，原生控件分别负责排版、焦点反馈和正文选区。单人和双玩家面板按各自玩家区域缩放。
