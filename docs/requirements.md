# SkyKeyYuyan 需求规格

SKY 为游戏和应用提供统一的语言输入服务，使开发者能够在不同设备和运行环境中复用语言组合、候选选择和文本编辑能力。首个完整接入环境为 Unity。

## 产品目标

1. 由框架完成语言解析、组字和转换，在缺少系统 IME 的环境中保持核心输入能力。
2. 以纯 C# 实现核心与自研语言引擎，兼顾 Unity IL2CPP 和 AOT 环境。
3. 让实体键盘、游戏手柄及其他输入设备复用同一套语言服务。
4. 提供可直接使用的输入界面，同时允许替换语言模块、设备适配器、文本目标、UI 和存档 Provider。
5. 通过 MIT 许可提供自研代码，并为发布资源提供整合的许可声明。

## 平台与运行条件

| 项目 | 要求 |
| --- | --- |
| 独立库 | .NET Standard 2.0 |
| 首个集成平台 | Unity |
| Unity 版本 | 最低 2020.3，主要验证 2022.3，兼容目标至 6.x |
| 当前操作系统验收 | Windows |
| 跨平台架构目标 | Windows、Android、iOS、Linux、macOS |
| 运行资源 | 语言资源随包提供，安装后首次使用即可离线运行 |
| 编译形式 | 支持普通托管执行与 AOT，语言注册使用显式工厂 |
| 分发 | 独立库使用 NuGet，Unity 包通过 OpenUPM 的 Scoped Registry 分发 |

其他操作系统的验证随对应平台适配和构建环境扩展。各版本的具体测试范围见[验证与交付计划](validation-plan.md)。

## 语言输入

| 语言能力 | 功能 |
| --- | --- |
| 简体中文全拼 | 连续拼音解析、单字与词语候选、基本整句候选、分段选词、剩余拼音继续输入、按组字历史回退 |
| 基础英语 | 直接输入文本 |
| 英语前缀补全 | 独立可选引擎，根据词首拼写生成候选，支持会话内实时开关 |
| 韩语拼写 | 现代两套式、复合元音、双辅音、收音组合与重分配、拼写回退 |

语言模块可以独立开发和分发。宿主通过语言标识和引擎标识显式选择实现。语言资源及默认键盘布局随相应语言包提供。

## 输入会话

框架支持多个相互独立的输入会话。每个会话具有自己的玩家、用户、语言列表、活动引擎、组字、候选、光标、选区、编辑模式和操作状态。

同一文本目标同时由一个 SKY 会话编辑。设备与玩家的对应关系由宿主管理。设备重连可继续暂停中的会话；不同玩家的输入和界面互相隔离。

宿主可以在运行期间添加语言。新语言完成初始化后供新会话选择。语言注册后不能注销。宿主也可以运行时添加、更新和删除自定义词组，相关候选查询随数据版本更新。

一个进程可以有多个运行时实例，其中一个是全局默认实例。会话默认使用全局默认实例，也可以指定其他实例。更换语言数据或实现配置时，宿主初始化新的运行时实例；新实例初始化成功后默认取代全局默认实例，已打开的会话继续使用原实例。

## Unity 交互

Unity 适配覆盖 UGUI InputField、TMP InputField 和通过独立适配包接入的 FairyGUI GTextInput。

默认接入支持 Legacy Input 与 Input System。宿主选择输入后端和设备范围，并按设备独立控制 SKY 的启用状态。编辑器控制面板展示依赖和模块状态，允许手动开关。

宿主决定文本框何时进入编辑态，SKY 默认跟随该状态打开输入界面。宿主可改用显式打开和关闭调用。

默认输入面板提供组字、候选、虚拟键盘、语言切换、文本编辑、完成、取消和恢复操作。界面打开后的整个流程可用手柄完成，包括多行文本、选区和错误恢复交互。

## 文本编辑

框架提供原输入框模式与自绘草稿模式。手柄默认使用自绘草稿模式，配置可按全局、文本目标和单次打开覆盖。

两种模式均支持单行和多行、选区替换、光标导航、退格、向前删除、全选、清空及目标文本验证。组字区独立展示尚未提交的语言内容。

组字与正文长度限制分别处理。正文写入按目标规则自动截断；自绘草稿在最终全文回填时处理目标限制。选择、取消、验证拒绝和外部正文变化的精确语义见[会话与文本编辑](session-and-editing.md)。

## 个性化与资源配置

宿主提供自定义词条的文本、匹配拼写、稳定标识和可选初始权重。SKY 根据已选择词条累计用户词频，并向引擎提供排序依据。

词频按用户标识持久化，同一用户在多个运行时实例中共享累计。单用户游戏可以只配置一个默认用户。用户词频可以在初始化时预加载，其余用户在打开会话后于后台加载，不阻塞输入。Unity 默认 Provider 使用 PlayerPrefs，宿主可接入自有存档系统。文本编辑结果与存档结果分别报告。

组字区、候选区及虚拟键盘文字支持按语言配置字体。正文和草稿正文使用宿主的混合语言字体方案；默认 UI 沿用对应框架的默认字体配置。

## 初始化和可恢复性

同步与异步初始化均返回结果，包含失败阶段和原因。首次初始化失败时结束本次初始化并回收本次取得的资源，调用者修正环境或配置后可重试。用户词频预加载失败不影响初始化结果。

运行时优先恢复受影响的查询或引擎。恢复流程保留有效状态、限制自动重试次数，并在持续故障时提供仍可编辑的字面输入状态。

文本写入和词频选择记录具有可识别的操作归属，恢复时依据实际执行结果处理，保持正文和计数一致。

## 使用方式

### 默认接入

宿主安装所需包，注册语言，初始化设备和玩家配置，将文本目标与对应 UI 根节点接入 SKY。玩家进入编辑态后，默认面板负责展示和输入；完成结果交回宿主业务。

### 自定义接入

宿主可以单独使用语言引擎查询候选，也可以使用输入运行时并自行实现文本目标、设备适配和界面。各模块通过接口和数据快照协作。

## 交付要求

交付物包括独立托管库、Unity 包、语言资源、默认界面资源、接口文档、示例与验证记录。开发仓库同时容纳 Unity 包开发项目和 FairyGUI 界面工程。

完整验证覆盖三种语言能力、三种文本框适配、两个输入后端、两种文本模式、双手柄双会话、运行时实例替换、离线初始化及恢复流程。
