# SkyKeyYuyan 会话与文本编辑

会话协调语言组合与正文编辑。组字保留语言特有的拼写和回退历史，正文保存已经接受的文本，两者通过明确的提交结果连接。

## 打开与配置

打开会话时读取目标正文和选区，取得目标编辑权，并固定所用的运行时实例、玩家、用户、语言列表、引擎实现及编辑模式。默认使用全局默认实例；未指定用户时使用默认用户。

编辑模式配置的优先级从高到低为单次打开、目标配置、全局配置。手柄默认采用自绘草稿模式。

初始语言优先使用目标或本次打开的显式配置；其余情况使用该玩家本次运行中记住的最近语言。最近语言不在本次列表中时，采用列表内的初始可用项。每个玩家独立记录最近选择。

## 状态组成

| 状态维度 | 含义 |
| --- | --- |
| 生命周期 | 已打开、暂停、已结束 |
| 语言工作状态 | 正常转换、恢复中、字面输入 |
| 查询状态 | 无查询、候选处理中、候选可用 |
| 待完成操作 | 正在等待转换的完成、切换语言或正文操作 |

这些维度分别保存在快照中。例如，会话可以处于暂停状态，同时保留一次尚未完成的候选查询。暂停期间保留编辑状态，需要写入正文的后续步骤在恢复活动后继续。

设备断开和应用失焦使会话暂停。宿主完成设备重新绑定或恢复应用焦点后可继续。面板内按键导航和候选焦点变化维持会话活动。

## 原输入框模式

会话从原正文和原选区开始。语言引擎产生最终提交片段后，通过原目标执行选区替换、验证和长度处理。快照中的正文跟随目标实际结果。

完成编辑保留当前正文。取消编辑丢弃仍在组字区的内容，已经写入目标的正文保持有效。

未提交的拼音、韩语拼写和已选片段显示在 SKY 组字区。目标正文只包含已经接受的文本。

## 自绘草稿模式

会话复制原正文和选区，建立独立草稿文本目标。组字提交写入草稿，用户可在自绘正文框内继续编辑。

草稿保留完整内容。结束编辑时，将最终草稿作为原目标的全文替换请求，由原目标适配器执行内容验证和长度处理。

取消时丢弃草稿及暂存词频记录。回填被拒绝时，会话保持打开，保留可继续修正的草稿和组字状态。结束操作中的暂态修改通过检查点恢复到一致状态。

## 组字提交

| 动作 | 处理 |
| --- | --- |
| 确认部分候选 | 记录所选片段，保留剩余拼写及回退历史 |
| 确认完成全部拼写的候选 | 形成最终文本编辑；接收结果确定后结束本次组字 |
| 完成编辑 | 先完成组字，再执行所需回填，返回会话结果 |
| 切换语言 | 先完成当前组字，再切换到会话列表中的目标语言 |
| 移动正文光标或选区 | 先完成组字，再执行目标导航 |
| 其他正文编辑动作 | 按相同提交规则处理当前组字，再执行向前删除、全选、清空等动作 |
| 取消 | 按当前编辑模式处理未完成内容并结束会话 |

中文、韩语在需要完成组字时先处理当前选中或首选转换，再处理剩余拼写；无法转换的部分保留原始文本。英语补全在用户尚未明确接受候选时保留已输入拼写。

普通目标验证拒绝使相关正文操作停止，组字保持可修正。已知的长度截断结果按下面的长度规则结束本次组字。

## 回退

组字包含实际输入和候选确认产生的历史步骤。B 优先回退组字；候选浏览和虚拟键盘焦点移动不构成组字步骤。

中文分段输入示例：

```text
输入 nihaoshijie
选择 你好                 -> 你好 + shijie
继续输入 a                -> 你好 + shijiea
按 B                      -> 你好 + shijie
再按 B                    -> nihaoshijie
再按 B                    -> nihaoshiji
```

一次完整转换已经提交到正文后，B 按正文退格处理。正文选区存在时删除选区；其余情况删除光标前的完整字符。

韩语在词内维持组合历史。例如组合中的 가나 可以回退为 간。语言特有的拆分由引擎处理，详见[语言引擎](language-engines.md)。

## 长度限制

长度限制只作用于写入正文的文本。目标剩余一个字的容量时，仍可输入完整 hen，再选择“很”。

### 原框插入

原框模式按插入操作计算可接收部分。保留原文中未被选中的前缀和后缀，在目标计数规则下截取可容纳的插入前缀，再执行选区替换。

| 原正文与光标 | 输入 | 长度上限 | 结果 |
| --- | --- | --- | --- |
| AB｜CD | XYZ | 5 | ABXCD |

目标适配器负责实现上述保留行为，并报告实际替换范围、接受文本和最新正文。具体控件的内置赋值或插入函数可以作为实现手段，其最终结果必须符合此契约。

### 草稿回填

草稿模式在最终回填时进行全文替换，按照目标计数规则截取最终全文的可接受前缀。

| 草稿完整内容 | 原目标长度上限 | 回填结果 |
| --- | --- | --- |
| ABXYZCD | 5 | ABXYZ |

### 结果解释

长度截断包括接受部分字符和接受零字符。结果确定后，本次组字结束，未被接受的余下文本由该次截断处理完毕。选区替换仍按其替换范围执行。

普通内容验证拒绝与长度截断分别返回状态。拒绝保留输入以便修正；长度截断返回已接受结果、实际文本和截断信息。

## 光标与 Unicode

正文和选区位置使用 UTF-16 偏移。选择锚点与活动端独立保存，扩展选择只移动活动端。

水平移动、删除和截断以完整 Unicode 字符为边界，至少保持代理对完整。垂直移动由目标适配器根据文本排版定位相邻行。组合字符和复杂字素的处理能力随目标运行时与适配实现记录在验证结果中。

右摇杆控制正文光标，LT 与右摇杆组合扩展选区。单行目标根据行模式处理垂直动作及换行请求。

## 异步候选和等待

L3、R3 只能确认与当前组字版本一致、已经展示的候选。新组字尚在查询时，界面显示处理中并保留用户可理解的状态。

X、Y 和需要先完成组字的正文动作等待当前有效转换结果。等待期间暂停该会话的内容编辑，保留取消入口。操作完成后继续执行原请求。

旧查询返回时，通过查询版本和引擎代次判断其适用性。会话结束后返回的结果不参与状态更新。恢复和重试规则见[恢复与词频存储](recovery-and-persistence.md)。

## 外部变化

适配器通过操作归属区分 SKY 自己的写入和宿主修改，并通过文本目标的 Changed 事件上报外部正文修改和目标失效。宿主外部修改原正文时，结束当前会话并保留宿主最新正文。

草稿会话因此结束时，丢弃待回填草稿及其暂存词频。原框会话保留目标的最新正文并丢弃未提交组字。目标失效或宿主明确中断时，按对应原因结束并释放编辑权。

宿主显式释放运行时实例时，仍打开的会话以「运行时释放」原因结束，按取消处理：草稿会话丢弃草稿及其暂存词频，原框会话保留已经写入目标的正文并丢弃未提交组字。每个会话发布一次结束通知。

## 完成结果

完成结果提供结束原因、最终正文和选区、回填结果、截断信息、存档状态及相关诊断。完成编辑与文本保存结果交给宿主，由宿主继续处理聊天、表单或其他业务。

会话结束通知发布一次。存档失败通过独立存储结果表达，已经完成的正文编辑保持有效。
