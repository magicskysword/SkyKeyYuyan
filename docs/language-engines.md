# SkyKeyYuyan 语言引擎

语言引擎将输入拼写转换为组字、候选和最终文本片段。各引擎共享统一契约，并保留对应语言的组合规则。

## 公共行为

每个会话使用独立引擎实例，组字、回退历史和临时候选互相隔离。只读词典、索引和默认键盘布局由语言模块共享。

引擎同步处理组合命令并产生状态变化，候选查询可以异步完成。候选携带消耗的拼写范围及已有词条标识，便于分段确认和个人词频统计。

候选查询只读取查询请求携带的不可变数据和模块只读资源，不访问引擎实例的可变状态，因此可以与同一实例上的组合命令处理并行执行。引擎需要把查询所用的组字信息完整放入查询请求，详见[接口与数据契约](api-contracts.md)。

目标正文长度由会话和文本适配器处理，语言引擎根据完整组字计算候选。

## 简体中文全拼

### 输入与转换

中文引擎接收完整拼音串，在音节和词条范围内解析可能的分段。候选包括单字、词语及由词条路径形成的基本整句结果。

转换流程由以下能力组成：

1. 规范化输入拼写，同时保留可恢复的原始输入。
2. 根据拼音音节及词典匹配产生分段路径。
3. 查询相应字符、词语和多音词读音。
4. 结合基础权重、自定义权重与用户选择次数排序。
5. 返回候选、消耗范围及构成结果的词条身份。

词典索引和路径排序实现围绕上述结果契约展开，候选质量通过常用字、常用词、多音词和整句样本验证。

ChinesePinyinModule 注册 `zh.full-pinyin`，语言标识为 `zh-Hans`。PinyinSpelling 将带调读音、ü 和音节分隔符规范化；查询保留原始拼写的范围映射。显式撇号约束音节边界，例如 `xi'an` 匹配 `xi an`。

中文索引同时提供前缀词条和有限宽度的词条路径搜索。完整转换优先展示，路径分值组合词典权重与用户词频；整句候选携带组成词条，部分候选携带已经消耗的原始拼写范围。

### 分段选择与回退

确认候选可消耗当前拼写的一部分。已选文字和余下拼写共同构成组字，继续输入追加到相应拼写区域。

历史记录保存输入和选择动作的状态变化。B 先撤回最近输入，再撤回最近选择，随后继续回退更早的拼写。完整示例见[会话与文本编辑](session-and-editing.md)。

全部拼写被转换并确认后，输出最终提交片段。目标接受或长度截断完成后结束组字；普通验证拒绝保留可修正状态。

### 整句候选

整句候选既可以来自已有整句词条，也可以由已有词条组合生成。引擎同时返回构成结果的词条标识。

选择已有整句词条时，统计该词条；选择组合句子时，统计其组成词条。输出文本和词条身份分别保存。

## 基础英语

核心提供英语直接输入实现。字符直接进入文本提交流程，正文编辑、选区替换和长度处理沿用会话规则。

该实现可独立服务于只需要基础字符输入的宿主。标准接入仍由宿主显式注册并配置其语言入口。

## 英语前缀补全

英语补全由独立语言包提供。引擎积累当前词的拼写，从离线词表中查询具有该前缀的候选。

EnglishCompletionModule 注册 `en.completion`，通过 LexiconModule 加载版本化词典。SpellingIndex 使用有序拼写范围查找前缀，排序组合基础权重和当前用户词频。候选导航越过页尾时加载下一页，返回前页时选择其末项。

原始输入保留大小写信息。候选展示和接收遵循当前输入的大小写形式。L3 或 R3 明确接受候选后，所选词进入提交流程；空格由用户输入动作产生。

空格、标点、完成编辑及语言切换等结束当前拼写的动作，在候选尚未被明确接受时提交原拼写。

### 实现选择

直接输入和前缀补全使用不同引擎标识，共用英语语言标识。宿主为会话的英语入口显式选择实现。会话语言菜单展示该入口选定的实现。

实现配置在运行时实例初始化时确定，实例内不能替换。更换实现或语言数据时初始化新的运行时实例；新实例默认取代全局默认实例，新会话使用新配置，已打开的会话继续使用原实例。详见[系统架构](architecture.md#运行时实例)。

### 会话内开关

补全实现提供实时开关，默认虚拟键盘展示当前状态及切换操作。关闭时先提交当前原始拼写，随后直接输入；重新开启从后续新输入开始积累补全拼写。

开关只作用于当前会话。受目标验证拒绝的提交仍按会话规则保留待修正输入。

## 韩语两套式拼写

韩语引擎实现现代两套式输入，通过初声、中声和终声状态组合现代韩文音节。

组合能力包括：

- 基本辅音和元音，以及双辅音输入。
- 复合元音和复合终声组合。
- 后续元音触发的终声重分配。
- 可按输入历史恢复的音节拆分与回退。

拼写在词内持续维护。空格、标点或显式提交结束相应组合，将结果交给会话。

例如输入产生 가나 时，第二个音节可能来自先前终声的重分配。B 回退最近的元音步骤后，组合恢复为 간。该行为由输入历史决定。

现代韩文字符组合的结构依据可参考 [Unicode 韩文音节边界说明](https://www.unicode.org/reports/tr29/#Hangul_Syllable_Boundary_Determination)，键盘背景可参考 [Microsoft 韩语 IME 文档](https://learn.microsoft.com/en-us/globalization/input/korean-ime)。本节定义 SKY 的交互与提交语义。

KoreanModule 注册 `ko.two-set` 实现。HangulComposer 接受两套式拉丁键位、兼容韩文字母和现代规范字母序列，按 [Unicode 音节组合规则](https://www.unicode.org/versions/Unicode17.0.0/core-spec/chapter-3/#G117718) 生成现代音节。双辅音与 Shift 元音由对应的大写键位输入。

TokenLanguageEngine 将同一文本片段中的词内拼写和分隔符按顺序处理。EngineStep.DeferredInput 交给会话在当前组字提交后继续执行，沿用同一操作标识和递增编辑序号。HistoryLanguageEngine 使用共享文本片段保存历史；多字符输入按完整字符建立回退步骤，检查点共享已有的不可变历史节点。

## 自定义词组

宿主拥有自定义词条定义及其持久化，运行期间通过稳定词条标识添加、更新或删除。词频由 SKY 的用户词频服务保存。

| 字段 | 中文 | 英语补全 |
| --- | --- | --- |
| 稳定词条标识 | 必需 | 必需 |
| 输出文本 | 简体中文字词 | 英语词条 |
| 匹配信息 | 显式拼音及音节信息 | 前缀匹配文本 |
| 初始权重 | 可选 | 可选 |
| 语言和引擎归属 | 对应中文模块 | 对应英语补全模块 |

同一语言、文本和读音的词条合并为一个候选。宿主显式提供的基础权重优先于词库基础权重，个人词频在此基础上继续参与排序。读音不同的条目分别保留。

更新权重时保持稳定词条身份及其个人词频。改变词条语义时，由宿主提供对应的稳定身份和更新数据。

自定义词条变更推进相关词典版本并刷新受影响的查询。仍在执行的旧查询通过版本判断保持与当前数据一致。

## 候选排序与选择记录

基础词库权重、自定义权重和用户选择次数是独立输入。个人词频按用户隔离，同一用户的会话共享其有效累计值，包括不同运行时实例中的会话。用户词频尚在后台加载时，候选先按基础权重排序，加载完成后刷新。

浏览候选只改变选择位置。成功确认候选产生 ChoiceRecord。记录以已有词条身份统计，正文截断不会将“你好”的选择记录改写为“你”。

引擎返回选择事实，运行时负责去重、草稿暂存及持久化，详见[恢复与词频存储](recovery-and-persistence.md)。

## 默认键盘布局

语言包提供平台无关布局数据，包括按键标识、显示标签、输出字符、功能动作和方向导航信息。表现包将布局映射到 UGUI 或 FairyGUI 控件。

布局支持宿主替换。确认、删除、语言切换、补全开关和取消等功能通过统一操作与会话连接。
