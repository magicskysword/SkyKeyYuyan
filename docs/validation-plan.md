# SkyKeyYuyan 验证与交付计划

验证以完整输入流程和明确的数据结果为依据，覆盖独立语言库、输入运行时、Unity 适配、默认表现和发布包。测试记录对应具体代码、数据和运行环境版本。

## 验证环境

| 环境 | 范围 |
| --- | --- |
| 独立 .NET 测试宿主 | 语言组合、回退、候选、文本编辑契约、词频、初始化和恢复 |
| Unity 2022.3 Windows Mono | 主版本完整输入及发布验证 |
| Unity 2022.3 Windows IL2CPP | AOT、资源加载、接口调用、输入和恢复验证 |
| Unity 2020.3 | 最低版本编译与核心输入流程 |
| 选定 Unity 6.x 版本 | 编译与核心输入流程 |

每份结果记录 Unity 补丁版本、Windows 版本、脚本后端、TMP、Input System 和 FairyGUI 的实际版本。主版本验证同时包括编辑器流程与 Windows Player。

## 运行时实例

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| RT-01 | 替换全局默认实例后，旧实例的会话继续输入 | 旧会话使用原实例完成；新会话使用新实例 |

| RT-06 | 在非默认实例上显式打开输入 | 会话使用指定实例的语言配置 |

## 文本编辑

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| TEXT-01 | 原框 AB｜CD 插入 XYZ，上限 5 | 得到 ABXCD |

| TEXT-03 | 目标仅可容纳一个中文字符，输入 hen | 拼写完整，最终可写入“很” |

| TEXT-05 | 最终提交被长度截断为零字符 | 返回确定的截断结果，组字结束 |
| TEXT-06 | 原框目标普通验证拒绝 | 保留待修正组字及目标实际状态 |
| TEXT-07 | 草稿最终回填被验证拒绝 | 会话保持打开，草稿与组字可继续修正 |
| TEXT-08 | 原框取消 | 已写正文保留，未提交组字丢弃 |
| TEXT-09 | 草稿取消 | 原正文保持，草稿与暂存词频丢弃 |
| TEXT-10 | 两种模式下宿主外部修改原正文 | 适配器触发 Changed，会话结束当前输入并保留宿主最新文本 |
| TEXT-11 | 选区替换、退格、向前删除、全选和清空 | 编辑范围及返回快照正确 |
| TEXT-12 | 多行文本右摇杆导航并使用 LT | 光标按排版移动，选区锚点和活动端正确 |
| TEXT-13 | 包含代理对的文本移动、删除和截断 | 保持代理对完整，偏移映射有效 |
| TEXT-14 | 完成编辑 | 完成结果准确，完成通知一次 |
| TEXT-15 | 编辑中销毁目标控件 | 适配器以目标失效触发 Changed，会话按目标失效结束并释放编辑权 |

各控件使用同一组预期文本结果验证适配层，特别检查控件自带验证、长度限制和事件回调对实际写入的影响。

仓库的 Unity 测试位于开发工程的 `Assets/Tests`。`node scripts/prepare-unity-validation.mjs --fairygui <SDK仓库路径>` 将开发工程和指定 SDK 复制到 `artifacts/UnityValidation`，保留该验证工程的 Library 缓存，并为 Windows 平台启用 FairyGUI 适配。FairyGUI 测试在 PlayMode 运行，使用真实 Stage、焦点和文本排版；基础服务及 UGUI/TMP 契约测试在 EditMode 运行。

## 候选并发

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| ASYNC-01 | 新组字查询先于旧查询返回 | 旧结果不能覆盖新状态 |

| ASYNC-06 | 查询期间更新自定义词条 | 受影响查询按新数据版本刷新 |

| ASYNC-08 | 暂停期间转换完成 | 需要写入正文的后续动作在恢复活动后处理 |
| ASYNC-09 | 查询执行期间同一引擎实例连续处理新输入 | Process 与查询并行无数据竞争，查询结果只依赖其请求数据，旧结果按版本失效 |

`prepare-unity-validation.mjs --profile core|ugui|tmp|input-system|modules-off` 创建不同依赖组合的编译验证工程，并移除该工程中的测试资产。`core` 不安装三个可选 Unity 依赖，`ugui` 仅安装 UGUI，`tmp` 安装 TMP 及其 UGUI 依赖，`input-system` 仅安装并启用 Input System，`modules-off` 安装依赖并关闭全部 SKY 可选模块。默认 `full` 保留完整开发配置及测试。

## Unity 组合验证

主验证版本覆盖下列维度，每个发布记录保留实际组合清单。

| 维度 | 组合 |
| --- | --- |
| 文本目标 | UGUI InputField、TMP_InputField、FairyGUI GTextInput |
| 输入后端 | Legacy Input、Input System |
| 编辑模式 | 原输入框、自绘草稿 |
| 编译后端 | Mono、IL2CPP |
| 默认表现 | UGUI、FairyGUI |
| 设备 | 单手柄、双手柄、键盘与手柄分别启停 |
| 生命周期 | 动态目标创建、焦点变化、设备断开和重新绑定、应用失焦、目标销毁 |

双手柄默认面板验证首先采用两个独立草稿目标，检查设备、候选、语言、选区和取消操作相互隔离。原框模式按对应控件的实际焦点实现执行验证。

同时启用 Unity 多种输入能力时，检查一次物理动作只产生一次 SKY 编辑。目标原有键盘处理与 SKY 设备路由的交接纳入验证。
