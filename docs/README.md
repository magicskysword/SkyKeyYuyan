# SkyKeyYuyan 开发文档

SkyKeyYuyan，简称 SKY，是提供独立语言输入能力的纯 C# 框架。语言引擎与输入调度可由 .NET 宿主独立使用，Unity 适配和默认输入界面提供游戏内的完整接入流程。

设计基线版本：1.0。生效日期：2026-10-16。

首个交付目标是在 Windows 的 Unity 游戏中，通过手柄在 UGUI、TMP 和 FairyGUI 文本框内完成简体中文全拼、英文和韩语输入。核心库以 .NET Standard 2.0 为兼容基线，Unity 最低版本为 2020.3，主要验证版本为 2022.3，兼容目标覆盖 Unity 6.x。

## 核心约定

SKY 自行完成语言组合和候选转换，安装语言资源后即可离线使用。核心和自研引擎采用纯 C#；平台 API、输入设备和具体 UI 由适配层接入。

宿主显式初始化服务、注册语言并指定启用设备。默认设备为手柄，标准示例注册英语和中文。

一个进程可以有多个运行时实例，其中一个是全局默认实例。实例内的语言只能添加，不能注销；更换语言数据或实现配置时初始化新实例，新实例默认取代全局默认实例。打开中的会话保持自己的实例和配置。

手柄默认使用自绘草稿界面。开发者也可选择直接编辑原输入框，或自行实现设备、文本目标和 UI。语言包、Unity 适配、FairyGUI 适配和两套默认输入界面按需分发。

## 术语

| 术语 | 定义 |
| --- | --- |
| 运行时实例 | 管理语言并提供输入的统一语言服务；进程内可以有多个，其中一个为全局默认实例 |
| 语言模块 | 管理某种引擎实现的描述信息、共享资源和实例工厂 |
| 语言引擎 | 处理一个会话内语言组合的独立实例 |
| 组字 | 尚未最终写入正文的原始拼写、已选片段及其编辑历史 |
| 候选 | 当前组字版本可选择的转换结果 |
| 正文 | 文本目标已经接受的内容；草稿模式中另有独立的草稿正文 |
| 文本目标 | 提供正文、选区、导航、验证和编辑结果的适配对象 |
| 玩家标识 | 宿主用于分配设备、UI 根节点和会话的标识 |
| 用户标识 | 宿主用于隔离个人词频存档的稳定标识 |
| 默认用户 | 运行时选项中指定、初始化时预加载的用户；会话未指定用户时使用 |
| 操作标识 | 会话内单调递增的操作序号，与会话标识共同确定一次操作 |
| 查询版本 | 标识生成一批候选时使用的组字、词典和设置状态 |
| 检查点 | 可恢复引擎组合状态及回退历史的不可变对象 |
| 选择记录 | 一次成功选择词条所产生的词频事件 |

## 文档使用

各专题文档规定系统行为和模块契约。接口章节使用 C# 表达设计签名；发布 API 参考随实现生成。测试矩阵和指标属于交付验收要求，执行结果随对应构建记录。

具体行为以所属专题为准：文本接收结果见会话文档，语言转换见语言引擎文档，故障恢复和存档见恢复文档。修改公共行为时，同步更新相关契约和验收用例。
